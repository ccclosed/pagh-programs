# paghbox 1.5.0: pkg install and symlink live check

Host: `python3 -m http.server 8766 --bind 127.0.0.1 --directory repo`
(ephemeral port from the run). Guest: QEMU `virt`, kernel 0.16.1 debug, 64 MiB
ext2, `--net`; the guest reaches the host as `10.0.2.2:8766`.
The package was built by `python3 tools/build_repo.py`: 743680-byte payload,
744441-byte `.ppkg`, SHA-256
`0a7f5c0230a09810553970771bf3fe12940b3fd12ac4e0b12f6dd3476a3595c4`.

Boot 1 installs from the freshly built `repo/`; boot 2 reuses the same disk
without a NIC and runs two installer-created symlinks, one of them a new batch-6
applet (`md5sum`) and one `cal`.

```text
==== install ====
Type 'help' for the command list.

pagh:rv64> pkg repo http://10.0.2.2:8766/
pkg: repo http://10.0.2.2:8766/
pagh:rv64> pkg index
pkg: index 1 package(s)
pagh:rv64> pkg install paghbox
pkg: installed paghbox 1.5.0
pagh:rv64>

Type 'help' for the command list.
```

`debugfs -R 'ls -l /bin' disk.img` shows the installed `paghbox` inode and
**94 symlinks** (one per `commands=` entry), including `md5sum`, `cal`, `gzip`,
`tar` and `patch`.
