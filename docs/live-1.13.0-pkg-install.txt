# paghbox 1.13.0: pkg install and symlink live check

Host: `python3 tools/live_pkg_install.py` (serve.sh equivalent: an HTTP
server on 127.0.0.1; the guest sees it as `10.0.2.2`).
Guest: QEMU `virt`, kernel release `/tmp/pagh-night2/riscv-feat-src/target/riscv64gc-unknown-none-elf/release/pagh`, 64 MiB ext2, `--net`.
Package: `repo/index` -> `paghbox 1.13.0`, 988108 bytes, SHA-256 `4a84a0d4deb1c7e5ca49ea594668637921f08b21d0578493a7a808c54c5eae92`,
payload 987104 bytes, 131 commands.
The disk starts empty except for the fixtures `abc.txt`, `hello.txt`,
`dd.txt` and `crlf.txt`; there is no pre-installed `paghbox`.

Boot 1 installs from the freshly built `repo/`; boots 2-4 reuse the
same disk without a NIC and run installer-created symlinks. Boot 2
checks the earlier applets (`dns`, `threads`), boot 3 `dd`/`nc`/`iconv`/
`printenv`, boot 4 the procfs applets: `free` prints its `Mem:` row,
`ps` its table, `df` the `procfs` mount (the test kernel has /proc).
