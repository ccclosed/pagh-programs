# paghbox 1.4.0: pkg install and symlink live check

Host: `python3 -m http.server 51679 --bind 127.0.0.1 --directory repo`
(ephemeral port from the run). Guest: QEMU `virt`, kernel 0.16.1 debug, 64 MiB
ext2, `--net`; the guest reaches the host as `10.0.2.2:51679`.

Boot 1 installs from the freshly built `repo/`; boot 2 reuses the same disk
without a NIC and runs two installer-created symlinks.

```text
==== install ====
Type 'help' for the command list.

pagh:rv64> pkg repo http://10.0.2.2:51679/
pkg: repo http://10.0.2.2:51679/
pagh:rv64> pkg index
pkg: index 1 package(s)
pagh:rv64> pkg install paghbox
pkg: installed paghbox 1.4.0
pagh:rv64>
```
