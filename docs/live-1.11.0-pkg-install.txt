# paghbox 1.11.0: pkg install and symlink live check

Host: `python3 tools/live_pkg_install.py` (serve.sh equivalent: an HTTP
server on 127.0.0.1; the guest sees it as `10.0.2.2`).
Guest: QEMU `virt`, kernel release `/home/oleg/pagh-riscv/target/riscv64gc-unknown-none-elf/release/pagh`, 64 MiB ext2, `--net`.
Package: `repo/index` -> `paghbox 1.11.0`, 935616 bytes, SHA-256 `7e3ceac1e0bf45771e4bdaade0d39e5a2e3b4ba09a0303dfea7f888a993b0ee2`,
payload 934656 bytes, 124 commands.
The disk starts empty except for `abc.txt` and `hello.txt`; there is no
pre-installed `paghbox`.

Boot 1 installs from the freshly built `repo/`; boot 2 reuses the same disk
without a NIC and runs installer-created symlinks, including the new
`dd` and `nc` applets, the 1.10.0 `dns` resolver and the 1.9.0
`threads` demo. `dd` is a real copy (`dd-payload`); `nc` with no
arguments must print its usage and exit 2.

```text
==== install ====
pagh:rv64> cd /mnt
pagh:rv64> pkg repo http://10.0.2.2:49975/
pkg: repo http://10.0.2.2:49975/
pagh:rv64> pkg index
pkg: index 1 package(s)
pagh:rv64> pkg install paghbox
pkg: installed paghbox 1.11.0
pagh:rv64> 
```
