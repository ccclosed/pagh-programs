# paghbox 1.12.0: pkg install and symlink live check

Host: `python3 tools/live_pkg_install.py` (serve.sh equivalent: an HTTP
server on 127.0.0.1; the guest sees it as `10.0.2.2`).
Guest: QEMU `virt`, kernel release `/home/oleg/pagh-riscv/target/riscv64gc-unknown-none-elf/release/pagh`, 64 MiB ext2, `--net`.
Package: `repo/index` -> `paghbox 1.12.0`, 952921 bytes, SHA-256 `c08ee296c56420dcdc227130c9dc761204306fdb680d8d5ce2fa18748b47d265`,
payload 951928 bytes, 128 commands.
The disk starts empty except for the fixtures `abc.txt`, `hello.txt`,
`dd.txt` and `crlf.txt`; there is no pre-installed `paghbox`.

Boot 1 installs from the freshly built `repo/`; boots 2 and 3 reuse the
same disk without a NIC and run installer-created symlinks. Boot 2
checks the earlier applets (`dns`, `threads`), boot 3 the new ones:
`dd` is a real copy (`dd-payload`); `nc` with no arguments prints its
usage and exits 2; `iconv` converts ASCII -> UTF-8 (`hello`);
`printenv` shows `PWD=/mnt`.

pagh:rv64>
