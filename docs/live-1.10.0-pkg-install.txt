# paghbox 1.10.0: pkg install and symlink live check

Host: `python3 tools/live_pkg_install.py` (serve.sh equivalent: an HTTP
server on 127.0.0.1; the guest sees it as `10.0.2.2`).
Guest: QEMU `virt`, kernel release `/home/oleg/pagh-riscv/target/riscv64gc-unknown-none-elf/release/pagh`, 64 MiB ext2, `--net`.
Package: `repo/index` -> `paghbox 1.10.0`, 917490 bytes, SHA-256 `75eb6007b4c6b368cd941643f246051855e8657ae9ee8eade703499357987d7a`,
payload 916536 bytes, 122 commands.
The disk starts empty except for `abc.txt` and `hello.txt`; there is no
pre-installed `paghbox`.

Boot 1 installs from the freshly built `repo/`; boot 2 reuses the same disk
without a NIC and runs two installer-created symlinks, including the new
`dns` applet and the 1.9.0 `threads` demo.

```text
==== install ====
pagh:rv64> cd /mnt
pagh:rv64> pkg repo http://10.0.2.2:32875/
pkg: repo http://10.0.2.2:32875/
pagh:rv64> pkg index
pkg: index 1 package(s)
pagh:rv64> pkg install paghbox
pkg: installed paghbox 1.10.0
pagh:rv64> 
```

